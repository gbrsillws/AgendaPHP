AgendaPHP

Sistema de agenda desenvolvido em PHP, com o objetivo de cadastrar, visualizar, atualizar e excluir contatos.

Sobre o projeto

O AgendaPHP é um sistema simples de gerenciamento de contatos. Ele permite organizar informações como nome, telefone e e-mail em um só lugar.

Funcionalidades

Cadastrar contatos

Listar contatos

Atualizar contatos

Excluir contatos

Consultar informações dos contatos

Tecnologias utilizadas

PHP

HTML

CSS

MySQL

Apache

Como executar

Clone o repositório:

git clone URL_DO_REPOSITORIO


Coloque o projeto na pasta do servidor web:

/var/www/html/


Inicie o Apache e o MySQL.

Acesse pelo navegador:

http://localhost/AgendaPHP
